---
description: Before creating any new component, check existing ones in the codebase and reuse or extend them instead of building from scratch.
---

When working on UI or backend code, always scan the existing codebase first.

- Search for components, utilities, hooks, or modules that already solve the problem before writing new ones. You can search for them under the `/components`, `/lib`, `/hooks` or `/services` directories.
- If a similar component exists, extend or adapt it rather than duplicating it.
- Respect the established design system: use existing tokens, colors, spacing, and typography conventions already in use.
- Never introduce a new pattern (layout, form, card, button style) if an existing one already covers the use case.
- If you must create something new, make it consistent with what already exists in naming, structure, and style.
